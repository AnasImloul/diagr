Press Place order to follow one request.
  1. 1

    The customer's browser sends the order to the global load balancer.

  2. 2

    Region A is active, so the load balancer sends the request there.

  3. 3

    The checkout API asks the pricing service for the total, then queues the order for the workers.

  4. 4

    A worker writes the order to the primary database.

  5. 5

    The write is replicated to region B, which stays ready to take over.
