Press Place order to follow one order.
  1. 1

    The phone app sends the order to the API gateway, which checks the token.

  2. 2

    The orders service reads the session from the cache and writes the order.

  3. 3

    One event goes on the bus. The orders service is done; it does not wait for anyone.

  4. 4

    Each consumer picks the event up on its own.
