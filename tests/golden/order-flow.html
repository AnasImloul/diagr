Press Place order to follow one order.
  1. 1

    Submit

    The customer places the order from the checkout page.

  2. 2

    Validate and queue

    The API checks the order and puts it on the queue, so a slow worker never blocks checkout.

  3. 3

    Process

    A worker takes the order off the queue and writes it to the database.

  4. 4

    Confirm

    Once the order is stored, the worker sends the confirmation email.
